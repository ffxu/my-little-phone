MY LITTLE PHONE — prototype 0.1

Files:
- index.html: the app
- manifest.webmanifest: installable web app settings
- sw.js: offline cache for supported browsers

Quick preview:
Open index.html in a modern browser. It is designed for a phone-sized screen.

Install on iPhone:
1. Host these files on an HTTPS website (GitHub Pages is a free option).
2. Open the hosted index.html in Safari.
3. Tap Share -> Add to Home Screen.
4. Launch My Little Phone from the new home-screen icon.

Notes:
- No accounts, ads, purchases, external links, or real calling/messaging.
- Sound can be muted with the speaker button.
- Speech/audio may require the first user tap due to iOS browser restrictions.
- This is an early prototype, not a child-safety lock. Use Guided Access on iPhone if you want to keep a child inside the app.
